# CreatorCut

Turn your raw footage into an edited video, with your own Claude Code or Codex chat doing the work. Choose captions, colour, music, styles and effects in Studio.

## Start here

Ask your AI to read **INSTALL.md** and install CreatorCut. Use **Claude Code (the Code tab in the Claude app)** or Codex, rather than the normal Claude chat tab. Wait until setup finishes. The folder opens in Finder so you can find it easily.

Installed. Now open it in a new chat:
**Claude:** use **Claude Code (the Code tab in the Claude app)**. Click **New session** → click the folder name under the message box → **Open folder…** → choose **CreatorCut** in your Home folder → **Open** → click **Trust**. Then type: **open Studio**.
**Codex:** **New chat** → choose the **CreatorCut** folder → choose **Full access** once if you accept its local access. Then type: **open Studio**.

## Make your video

Add raw files and B-roll in Studio. Choose a style and up to two effects. You can also add a reference video or a TikTok, Instagram or YouTube link. If a link cannot be read, drop the downloaded video instead.

Press **Make my video**. Make starts by itself in Claude; if it doesn't within 30 seconds, type **continue**. In Codex, type **continue**. Keep your chat open and answer any genuine question or permission request there.

Watch Editor, then **Download** your finished video. Add timeline feedback and press **Update video** to make changes. **Save as preset** keeps the style for next time. Your footage and earlier versions stay saved. If an effect does not suit your clip, your chat explains and finishes the rest.

Captions: English and other Latin-alphabet languages.

Keep your Mac awake and plugged in during an edit. Close heavy apps and leave several GB free, plus 2.5 GB for each edit.
