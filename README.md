# CreatorCut

**Your footage. Your style. Your AI video editor.**

## Start here

Open **Codex desktop** or **Claude Code on your computer**. Copy this sentence into a new chat:

> Install CreatorCut from https://github.com/nategoldai/creatorcut-updates and open Studio inside this app. Follow INSTALL.md. Keep any existing videos, presets and editing memory.

That’s it. Your AI handles the download and setup, then opens Studio. You don’t need to download a ZIP or learn GitHub.

First setup needs internet, several GB of storage and time to download the editing tools. CreatorCut uses **your own signed-in Codex account and its usage limits**, including when you open it from Claude Code. A Claude subscription alone does not supply this editor. Ordinary mobile/web chats without local computer tools cannot install this desktop application.

## Make your first video

1. Add your raw files and optional B-roll in **Studio**.
2. Add a reference video, choose a style or use a saved preset. Describe what you want.
3. Click **Make my video**. Watch progress in **Editor**.
4. Add feedback on the timeline, update your video and download the finished result.

Save a named preset to reuse that video’s style. Lasting editing preferences stay in your private local memory.

## Updates

Use the same installation link every time. Existing users install new versions with **Install update** inside CreatorCut. It checks when the app starts and every six hours while open. Your videos, presets and editing memory stay on your computer.

The package stored here is public. Customer recordings, projects, accounts and personal presets are not included.
