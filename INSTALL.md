# Install CreatorCut

1. In **Claude Code (the Code tab in the Claude app)** or Codex, ask: **Read this repository and install CreatorCut using install.sh.** Choose a new CreatorCut folder. No system Python is needed.
2. Wait for setup to finish. Finder shows the installed folder.
3. Open that folder in a new chat:

Installed. Now open it in a new chat:
**Claude:** use **Claude Code (the Code tab in the Claude app)**. Click **New session** → click the folder name under the message box → **Open folder…** → choose **CreatorCut** in your Home folder → **Open** → click **Trust**. Then type: **open Studio**.
**Codex:** **New chat** → choose the **CreatorCut** folder → choose **Full access** once if you accept its local access. Then type: **open Studio**.

4. Studio opens. Add footage and press **Make my video**. Keep the Claude chat open. If it doesn't start within 30 seconds, type **continue**. In Codex, type **continue** after Make or Update video.
